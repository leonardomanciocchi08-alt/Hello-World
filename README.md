# Progetto 5E

Autori: Davide Giovannangeli, Leonardo Manciocchi, 5E

## Descrizione
Questo programma è una semplice applicazione Java che stampa un messaggio iniziale in console. È stato creato come base per iniziare a lavorare con Java e comprendere la struttura di un progetto minimale.

## Istruzioni per eseguire il programma
1. Apri il terminale o il prompt dei comandi nella cartella del progetto.
2. Compila il file Java:
   ```bash
   javac Main.java
   ```
3. Esegui il programma:
   ```bash
   java Main
   ```

Se tutto è corretto, verrà visualizzato il messaggio "Hello World".
